## blackbox, hievent и `/dev/bbox`

**Кратко:** `/dev/bbox` создаёт драйвер **hievent**, а не blackbox. Имя узла
историческое. В ядре включается параметром `CONFIG_HIEVENT`. При `=y` драйвер встроен в ядро, отдельного .ko в /system/lib/modules не будет

Обе подсистемы — дополнения OpenHarmony к ядру (`drivers/staging/`), в mainline
Linux их нет.

> Для LiteOS (mini/small) есть отдельная библиотека `base/hiviewdfx/blackbox` с той же схемой (`BBoxNotifyError`, `SystemModule*`) — к Linux-ядру отношения не имеет.

**blackbox** — «бортовой самописец» для тяжёлых сбоев: паника ядра, сбойная перезагрузка. В момент аварии снимает дамп с зарегистрированных модулей, хранит его так, чтобы он пережил перезагрузку, а после загрузки пишет лог в файл. Узлов не создаёт, работает целиком внутри ядра. Срабатывает редко, только при аварии.

**hievent** — канал событий: кольцевой буфер в ядре плюс узел `/dev/bbox`. Через него ядро и init передают обычные события в hiview. Ничего не переживает перезагрузку, ничего не пишет в файлы, к авариям прямо не привязан. Используется постоянно, пока кто-то пишет события.
