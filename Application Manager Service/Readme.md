# Application Manager Service (appmgr)
Ключевой системный сервис OpenHarmony, который отвечает за полный жизненный цикл всех приложений и управляет их процессами. Он координирует запуск, остановку, заморозку и смену состояний приложений (от активного на переднем плане до фонового), тесно взаимодействуя с модулем appspawn для безопасного порождения процессов под изолированными правами пользователя (UID). Именно appmgr распределяет системные ресурсы, следит за стабильностью работы программ и оптимизирует потребление памяти и энергии, переводя неиспользуемые задачи в спящий режим.
