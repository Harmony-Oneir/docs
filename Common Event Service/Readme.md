# CES (Common Event Service, SA 3299)

CES (Common Event Service, SA 3299) — это ключевой системный сервис межпроцессного взаимодействия и распространения событий в архитектуре OpenHarmony. Его основное назначение — обеспечение централизованной инфраструктуры публикации, подписки и асинхронной рассылки системных и пользовательских уведомлений (Publish-Subscribe) между различными компонентами ОС, фоновыми службами и приложениями.

#### Ключевые функции и назначение в системе

* **Шина межпроцессных и внутрипроцессных событий**
CES действует как единый диспетчер сообщений, который позволяет одной службе или приложению сообщить остальной системе о наступлении определенного события (например, об изменении статуса сети, подключении зарядного устройства, загрузке системы или завершении работы приложения), не зная заранее, кто именно должен на это отреагировать.
* **Поддержка синхронных и асинхронных событий**
  
  - **Асинхронные события (Common Events)**: Транслируются всем подписанным получателям одновременно. Получатели обрабатывают их в фоне без блокировки источника.

  - **Синхронные события**: Позволяют получателям обрабатывать уведомление последовательно, с возможностью перехвата или изменения результата (например, упорядоченная цепочка широковещательных запросов).
 
# Сборка

Для сборки используйте команду `./make.sh ces` в контейнере. Результат сборки находится по пути `out/oneir/notification/common_event_service/`:

| Название | Описание |
|---|---|
| `libcesfwk_services.z.so` | Реализация SA **CommonEventService** (3299): принимает события от публикующих сервисов, хранит список подписчиков и рассылает события тем, кто подписан. Проверяет права на публикацию и получение событий, хранит «липкие» события (последнее значение события, которое получает каждый новый подписчик) |
| `libcesfwk_core.z.so` | Ядро клиентской части: IPC-прокси для обращения к SA 3299, общие структуры данных события (имя, параметры, данные) и подписки |
| `libcesfwk_innerkits.z.so` | Клиентский интерфейс для системных сервисов: `CommonEventManager::PublishCommonEvent`, `SubscribeCommonEvent`, `UnSubscribeCommonEvent`. Через него, например, `wifi_manager` подписывается на события и рассылает свои |
| `libstatic_subscriber_ipc.z.so` | IPC-интерфейс «статических подписчиков»: приложений, объявивших подписку в своём описании, которых CES запускает при наступлении события, даже если они не работают. Без менеджера приложений эта функция не используется, но библиотека нужна как зависимость |
| `cem` | Консольная утилита для отладки: опубликовать событие (`cem publish -e <событие>`), посмотреть подписчиков и «липкие» события (`cem dump`) |
| `ces.para` | Параметры CES по умолчанию |
| `ces.para.dac` | Права доступа к параметрам CES: кто может их читать и изменять |
