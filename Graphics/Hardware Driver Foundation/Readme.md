# Hardware Driver Foundation
HDF это ключевая подсистема OpenHarmony, которая отвечает за работу с аппаратным обеспечением устройств. Он представляет единый драйверный каркас, который позволяет писать драйверы один раз и использовать их на самых разных устройствах.
HDF разделен на уровни:
* **hdf_devmgr**  — менеджер устройств. Он отвечает за управление жизненным циклом драйверов, их загрузку, регистрацию
* **hdf_devhost** — процесс-контейнер в пользовательском пространстве (User space), внутри которого исполняются драйверы конкретных аппаратных модулей (например, сенсоры, дисплей, Bluetooth). Это обеспечивает изоляцию: если упадет драйвер в `devhost`, вся система не улетит в Kernel Panic.

Система hdi построена так, чтобы максимально упростить жизнь разработчикам железа и драйверов. В OpenHarmony уже есть готовый системный сервис. Он берет на себя всю «рутину»: общается с операционной системой, принимает межпроцессные вызовы, отвечает за безопасность и IPC. Таким образом для написания драйвера достаточно написать Vendor Driver Interface. Интерфейс, который он должна реализовать, находится в файле `buffer/hdi_service/include/idisplay_buffer_vdi.h`.

# Сборка 
Для сборки используйте команду `./make.sh hdf` в контейнере. Результат сборки находится по пути `/out/oneir/hdf/drivers_devhost/` и `out/oneir/hdf/hdf_core/`:
| Зависимость | Описание |
|---|---|
| `hdf_devmgr` | Менеджер устройств HDF: читает HCS-конфиг, через init запускает процессы-хосты, ведёт реестр устройств и сервисов. |
| `hdf_devhost` | Процесс-хост драйверов: init запускает его с именем конкретного хоста, он загружает драйверы (`.z.so`) этого хоста. |
| `libhdf_host.z.so` | Логика хоста: загрузка драйверов, вызов `Bind/Init/Release`, публикация сервисов драйверов. |
| `libhdf_utils.z.so` | Базовые утилиты HDF: `HdfSBuf`, списки, синхронизация, доступ к HCS-конфигу, логирование. |
| `libhdf_ipc_adapter.z.so` | Адаптер HDF к IPC OpenHarmony: `HdfRemoteService`, связь `HdfSBuf` и `MessageParcel`. |
| `libhdi.z.so` | Клиентский API HDI: `HDIServiceManager`, `IDeviceManager`, получение и регистрация сервисов. |
| `libhdi_base.z.so` | Базовые C++ классы HDI: `HdiBase`, очереди в разделяемой памяти (`HdiSmq`). |
| `libpub_utils.z.so` | Общие вспомогательные функции, которые используют другие модули `hdf_core`. |
