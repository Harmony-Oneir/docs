# Hardware Driver Foundation
HDF это ключевая подсистема OpenHarmony, которая отвечает за работу с аппаратным обеспечением устройств. Он представляет единый драйверный каркас, который позволяет писать драйверы один раз и использовать их на самых разных устройствах.
HDF разделен на уровни:
* **hdf_devmgr**  — менеджер устройств. Он отвечает за управление жизненным циклом драйверов, их загрузку, регистрацию
* **hdf_devhost** — процесс-контейнер в пользовательском пространстве (User space), внутри которого исполняются драйверы конкретных аппаратных модулей (например, сенсоры, дисплей, Bluetooth). Это обеспечивает изоляцию: если упадет драйвер в `devhost`, вся система не улетит в Kernel Panic.
