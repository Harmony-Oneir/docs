# Memory Manager Service (memmgr)
Специализированный системный сервис в архитектуре OpenHarmony, отвечающий за комплексное управление оперативной памятью и предотвращение ситуаций нехватки ресурсов (Out-Of-Memory, OOM). Он непрерывно мониторит нагрузку на систему, анализирует степень важности запущенных процессов и уровень их активности (от активного UI до глубокого фона), после чего динамически перераспределяет память или инициирует мягкое завершение (kill) наименее приоритетных фоновых процессов и кэшей, чтобы гарантировать плавную работу критически важных интерфейсов и предотвратить аварийное падение всей операционной системы.
