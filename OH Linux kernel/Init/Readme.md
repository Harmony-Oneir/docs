

# Сборка
Для сборки используйте команду `make.sh rootfs_init` в контейнере. 
Для сборки конфигурационных файлов файлов init используйте команду `make.sh rootfs_services_cfg`.

Результат сборки находится по следующим путям:
* `out/oneir/startup/init/`
* `out/oneir/thirdparty/mksh/sh`
* `out/oneir/thirdparty/toybox/toybox`


### out/oneir/startup/init/
| Файл | Описание |
|---|---|
| `init` | Первый процесс системы (PID 1). Запускает и контролирует сервисы по файлам `*.cfg`, содержит сервис системных параметров, назначает сервисам права и токены, создаёт песочницы. |
| `ueventd` | Демон устройств: получает от ядра события `uevent` и создаёт файлы в `/dev` с нужными правами и владельцами (по `ueventd.cfg`). |
| `begetctl` | Утилита управления `init` из командной строки: запуск и остановка сервисов, работа с параметрами и песочницами, перезагрузка. Многие команды (`param`, `reboot` и другие) — ссылки на неё. |
| `param` | Утилита для работы с системными параметрами (`param get`, `param set`, `param ls`, `param wait`). Скорее всего, это ссылка на `begetctl` или его урезанная версия. |
| `libbegetutil.z.so` | Базовая библиотека `init`: клиентский API системных параметров (`GetParameter`/`SetParameter`), логирование и вспомогательные функции. Её используют почти все сервисы OpenHarmony. |
| `libbeget_proxy.z.so` | Клиентская библиотека для обращения к `init` из других процессов: управление сервисами, перезагрузка и другие запросы к `init`. |
| `libsystemparam.z.so` | Библиотека доступа к системным параметрам. Судя по названию, это обёртка для других компонентов. Точное назначение лучше проверить по `BUILD.gn`. |
| `libparam_watcher.z.so` | Подписка на изменения параметров: процесс получает уведомление при изменении параметра. Работает через системный сервис `param_watcher` (требует `samgr`). |
