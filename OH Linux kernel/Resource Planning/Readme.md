Подсистема планирования ресурсов (`foundation/resourceschedule`) представляет собой централизованный диспетчер операционной системы, который в реальном времени управляет распределением процессорного времени, оперативной памяти и энергии между приложениями и системными сервисами. Анализируя действия пользователя и текущий жизненный цикл ПО, подсистема координирует работу специализированных модулей (планировщика приоритетов `ressched`, менеджера памяти `memmgr`, контроллера производительности `soc_perf` и др.) и задействует механизм контрольных групп (`cgroup`) для изоляции процессов, назначения им динамических приоритетов и оптимизации общего энергопотребления устройства.
