# docs
Цель проекта Harmony Oneir — создание операционной системы для архитектуры x64 на базе OpenHarmony. В данном репозитории описаны этапы компиляции проекта и его адаптации.
Поскольку OpenHarmony тесно интегрирована с собственным ядром Linux, проект содержит ряд патчей, необходимых для запуска операционной системы на стандартном ядре Linux.
Отказ от оригинального ядра OpenHarmony на данном этапе обусловлен стремлением упростить процесс разработки. Это временное решение, не предназначенное для использования на реальных устройствах. По завершении текущего этапа разработки планируется переход на оригинальное ядро OpenHarmony.
Процесс дальнейшей работы можно разделить на следующие этапы:
* Загрузка исходного кода OpenHarmony и кодовой базы компонентов Oneir.
* Запуск контейнера Docker и установка инструментов, необходимых для сборки.
* Компиляция и запуск минимальной системы.
